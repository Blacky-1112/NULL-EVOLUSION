概要

C++とDirectX11を用いて制作した個人開発の3Dアクションゲームです。
就職作品として約半年かけて制作しました。ゲームエンジンに依存せず、低レイヤからゲーム開発への理解を深めることを目的として開発を行いました。

プレイヤー操作、敵AI、カメラ制御、パーティクル、UI、シーン管理など、ゲーム全体のシステムを自作しています。単に機能を実装するだけではなく、「遊んでいて気持ちいいゲーム体験」を意識し、演出面や操作感の調整を繰り返しました。

工夫した点
ゲーム体験を意識した演出

ゲームプレイ中の爽快感や迫力を向上させるため、カメラシェイクやエフェクト演出、アニメーション制御などを実装しました。特に、空から隕石が降ってくる攻撃演出は、迫力が出るよう何度も調整を行ったお気に入りの要素です。

保守性を意識した設計

機能追加に伴いコード量が増加したため、Scene・Manager・GameObjectなど役割ごとにクラスを分割し、管理しやすい構成を意識しました。

フレームレートに依存しない挙動

デルタタイムを利用した更新処理を導入し、実行環境によってゲーム速度が変化しないよう改善しました。

苦労した点

特に苦労したのは、GPU側へ値を渡す処理です。描画に必要なデータが正しく反映されず、意図した表示にならない問題が多く発生しました。

その際は、CPU側とGPU側の処理を整理しながらデバッグを繰り返し、どの段階で問題が発生しているかを切り分けながら原因を特定しました。

この経験を通して、低レイヤの処理を意識しながら問題解決を行う力を身につけました。
